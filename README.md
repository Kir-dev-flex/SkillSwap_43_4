# SkillSwap

A team learning project for finding people who can exchange practical skills — from languages and design to business and home projects.

## Product flow

- Browse skill offers and filter the catalogue
- Search with a debounced interface
- Open detailed skill and user pages
- Add offers to favourites
- Register, sign in, and edit a profile
- View notifications and protected account pages
- Explore responsive desktop and mobile layouts

## Technical highlights

- React and TypeScript application
- Redux Toolkit state management
- React Hook Form based forms
- Mock asynchronous API backed by local JSON data
- Reusable components and CSS Modules
- Hash-based routing for reliable GitHub Pages navigation
- ESLint, Prettier, Stylelint, and Vitest tooling

## Stack

React 19, TypeScript, Redux Toolkit, React Router, React Hook Form, Axios, Vite, CSS Modules.
